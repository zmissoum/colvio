Colvio — the free, open-source toolkit for Microsoft Dynamics 365 / Dataverse, right in your browser.

Query, load, inspect, test the Web API and audit your org from one side panel. Colvio uses the session you are already signed in with: no app registration, no API key, no account, no subscription. It talks only to your own Dynamics 365 host — no analytics, no telemetry, no external server.

24 modules for consultants, admins and developers. Colvio adapts to your rights: admin-only modules stay hidden for standard users, and every write still goes through Dataverse's own security.

WHAT'S NEW
• Script Console — run JavaScript on the Web API with your session, for what no screen does: fill a lookup from another table, fix data by rules. A dry run lists every write without sending it; the real run keeps a rollback journal that puts every row back in one click.
• Who runs what — every identity behind your automation and what it is (person, service account, app registration, built-in user, team), the account each connection is signed in with, and whose rights each workflow and plug-in step runs with.
• Record activity — save a record and see what the save set off: plug-ins in execution order (duration, cascades, exception, full trace), system jobs and cloud flows; click a failure for its error, the step behind it and its recent runs; "log every plug-in" for 15–60 minutes, reverted by itself.
• Record access — pick a user and get Dataverse's own yes / no for each right on a record, why (role, team, depth or share) and what would grant a no.
• Health check — one report on what silently hurts the environment: failing and suspended jobs, flows owned by disabled users, plug-ins firing on every update, unbound connection references, empty environment variables, users without a role, unmanaged solutions in production, growing log tables — each with what to do.
• Change things, not just look — switch plug-in steps on / off and set their filtering attributes; add, rename, reorder and delete choice values; create columns in bulk from a CSV / Excel sheet; edit and publish web resources. Every write confirmed, twice on production.
• Data model — per column: fill rate (exact, even on millions of rows), what blocks deleting it or everything that uses it, its solution layers; a data dictionary of every column to CSV / Excel.
• Explorer — SQL UPDATE / DELETE always previewed; "To file" streams every row to CSV / Excel whatever the size; save any query as a personal view; paste any Web API URL.
• Built for big orgs — set-based reads instead of one request per user or role, a real API meter against Dataverse's quota, nothing leaves your browser.

DATA
• Data Explorer — query any table with a visual Builder, OData, FetchXML or SQL (native ?sql= or transpiled; UPDATE / DELETE with a mandatory preview). No 5,000-row cap, virtual scrolling on 10k+ rows, AND/OR filter groups, relational filters ("accounts with no open opportunity"), parent and child expands. Edit cells in place, or bulk update / delete on a fast $batch pipeline — values typed and validated against the column's metadata, lookups included. Duplicate finder, query tabs, history, saved queries, save as personal view, Excel / CSV / JSON exports, and "To file" to stream every row whatever the size.
• Data Loader — CSV, TSV or Excel in (UTF-8, UTF-16 or Windows-1252 files read as they are); CREATE, UPSERT (GUID or alternate key), UPDATE-only and DELETE. Parallel $batch (about 3–4k records per second), a live per-row log with the exact Dataverse error, label → option value transforms, EU / US dates, mapping templates. Safety net: dry run, rollback of what a run created, delta mode, pre-flight checks, retry of transient failures only, optional bypass of custom plug-ins and workflows.
• Recycle Bin — restore deleted records server-side, with who deleted them and every platform limitation explained.
• Show All Data — every field of the record open in your tab, with logical names and types, editable in place (field security still enforced). Record activity: save the record and see what it triggered — plug-in chains, system jobs, and which cloud flows run or not, and why. Record access: pick a user and get Dataverse's own yes / no for each right on the record, why, and what would grant a no. Field-level change history, and a Business Process Flow manager for admins.

DEVELOP
• Script Console — run JavaScript on the Web API with your session: a complete client (paging, FetchXML, create / update / upsert / delete, links, actions, $batch), a dry run that lists every write without sending it, then a real run you can roll back. The script runs isolated, without network.
• API Tester — a Postman for Dataverse with automatic authentication: GET / POST / PATCH / PUT / DELETE, header autocomplete, JSON editor with validation, templates, a history with secrets redacted, copy as cURL.
• Metadata — tables, columns and choices, Virtual and Elastic table filters; per column: fill rate, dependencies (what blocks a delete, everything that uses it), solution layers; data dictionary export; edit choice values; create columns in bulk from a CSV / Excel sheet.
• Automation — every plug-in step, classic workflow, cloud flow, business rule, action and business process flow registered in the org; enable / disable steps and set their filtering attributes; who runs what — every identity behind the automation (person, service account, app registration, built-in user, team), the account each connection is signed in with, and a "Runs as" column for workflows and plug-in steps.
• Web Resources — edit and publish scripts, styles and pages; search a column name inside the scripts shown.
• Apps — what each model-driven app really exposes, including the "all forms / all views" state the maker portal never shows; view filters decoded to plain language.
• Relationships & Schema — an interactive relationship graph, and an ERD canvas exportable as PNG, SVG or Mermaid.
• Solutions — components resolved to readable names, and solution compare within an org or across orgs.
• Environment Variables — defaults, overrides, and the classic trap surfaced first: variables with no value at all.
• Translations — field labels in every provisioned language, CSV export / import, automatic publish.

ADMIN
• Users & Licenses — access mode, license type, roles, last sign-in; unused licenses at a glance. Bulk settings: email tracking, time zone, language, currency and mailbox sync options for many users at once, with readable values and a per-user result.
• Business Units — hierarchy tree and org chart, members, bulk moves by pasting a list of emails.
• Security Audit — role privileges in plain words, a table × operation matrix, sensitive rights flagged, who holds each role (users and teams), an org-wide "who can do what" scan, and the roles that hold any one privilege (Export to Excel, Bulk Delete…). Bulk role assignment.
• Teams — owner, Entra group and access teams, their members and their inherited roles.
• Adoption — access events, DAU / WAU / MAU and stickiness, adoption per business unit, paid seats that never sign in, and a 5-slide PowerPoint report with native charts.
• Login History — each user's access timeline from the user-access audit, app vs web services (API).
• Storage — row counts and file storage per table, the tables that grow silently and how to clean them.
• Health check — one report on what silently hurts the environment (failing and suspended jobs, flows owned by disabled users, unfiltered plug-in steps, unbound connection references, empty environment variables, users without a role, unmanaged solutions in production, log table sizes), each with what to do.
• System Ops — stuck system jobs (bulk cancel / resume), plug-in trace logs, cloud flow run history.

SAFE BY DESIGN
• Your existing Microsoft Entra ID session — no credentials stored.
• Requests go only to the Dynamics 365 host you are on; the API Tester refuses any other domain, and the Script Console reaches only the Web API.
• Typed confirmation before bulk deletes, confirmation before bulk updates, an extra confirmation on production.
• Input validation against OData injection; spreadsheet formula protection on every export.
• Filter values and secrets are redacted from histories.
• Colvio cannot bypass Dataverse permissions: what you can't do in Dynamics 365, you can't do in Colvio.

Works on every Dynamics 365 / Dataverse region (*.dynamics.com). Dark and light themes, English / French interface, command palette (Ctrl+K).

100% free and open source — no freemium, no Pro tier. Source code and documentation: github.com/zmissoum/colvio
