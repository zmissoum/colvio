# Colvio — LinkedIn videos, Posts 40 → 57

Media only: this branch holds no code and is never merged into `main`.

`linkedin/post-NN_<module>.mp4` is the video of Post NN, 1080p, English captions, demo data. Each video opens on its title card, so LinkedIn's default thumbnail is clean. `linkedin/linkedin-posts-40-57.md` holds, for each post, the date, the text to paste and the first comment.

- Batch 2 (Posts 40 → 46): Jan 5 → Feb 16, Tuesdays 8:30.
- Batch 3 (Posts 48 → 57): Feb 23 → Apr 27, Tuesdays 8:30. Schedule from Jan 27, once the Chrome Web Store shows v1.11.219 or later.

Get them on your PC, inside your clone of the repo:

```
git fetch origin linkedin-videos
git worktree add ..\colvio-linkedin-videos linkedin-videos
```

The files land in `..\colvio-linkedin-videos\linkedin\`, next to your clone, and your working branch is not touched. The full plan is `linkedin-plan-videos.md` on `main`.
