## Overview / Description (max 2,000 characters — 1835)

```text
🔍 Colvio — the free toolkit Dynamics 365 has been missing

Colvio is a free, open-source browser extension for Dynamics 365 / Dataverse consultants, admins and developers. It runs in your browser on the session you're already signed in with: no account, no app registration, no telemetry. It talks only to your own org.

21 modules:
🔎 Data Explorer — Builder, OData, FetchXML or SQL; no 5,000-row cap; inline and bulk edits
📥 Data Loader — Excel / CSV import with dry run, delta and rollback
🗑️ Recycle Bin — restore deleted records server-side
📄 Show All Data — every field of a record, editable in place
🧪 API Tester — Web API calls with automatic authentication
📚 Metadata — tables, columns, option sets, data dictionary, schema diff
⚡ Automation — plug-in steps, workflows, cloud flows, business rules
🧩 Apps — what each model-driven app really exposes
🔗 Relationships and 🗺️ Schema — relationship map and ERD
📦 Solutions — components, and DEV vs PROD compare
⚙️ Environment Variables — missing values, typed edits
🌍 Translations — labels in every language
🎫 Users & Licenses — licenses, last login, settings in bulk
🏢 Business Units — tree, org chart, bulk moves
🛡️ Security Audit — who can do what, role matrix
👥 Teams — members and the roles they inherit
📈 Adoption — DAU / WAU / MAU, users who never sign in
🕐 Login History — access timeline from the audit
💾 Storage — what fills your Dataverse capacity
🔧 System Ops — system jobs, plug-in traces, flow runs

Every list exports to CSV and Excel. Production gets an extra confirmation, and nothing bypasses Dataverse security: what you can't do in Dynamics 365, you can't do in Colvio.

100% free, open source (MIT), 462 automated tests.

Chrome Web Store: https://chromewebstore.google.com/detail/edieednbdaclheikneelkjfbckibhdgl
Source code: https://github.com/zmissoum/colvio
```
